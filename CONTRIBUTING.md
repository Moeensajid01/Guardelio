
# 🤝 Contributing to Guardelio

Thank you for your interest in contributing to Guardelio! We welcome contributions that improve cybersecurity training, simulation experiences, and overall platform functionality.

## 🚀 Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make and test your changes.
5. Submit a pull request.

```bash
git checkout -b feature/your-feature
git add .
git commit -m "feat: describe your changes"
git push origin feature/your-feature
```

## 💡 Ways to Contribute

- Report bugs and suggest improvements.
- Develop new cybersecurity scenarios.
- Improve UI/UX and accessibility.
- Enhance backend functionality and security.
- Improve documentation and testing.

## 📋 Contribution Guidelines

- Write clean, readable, and maintainable code.
- Follow the existing project structure.
- Test changes before submitting.
- Keep pull requests focused and descriptive.
- Never commit credentials, API keys, or sensitive data.

## 📝 Commit Convention

| Prefix | Purpose |
|---|---|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `docs:` | Documentation |
| `refactor:` | Code improvement |
| `style:` | UI or formatting changes |
| `test:` | Testing |
| `chore:` | Maintenance |

## 🔀 Pull Requests

Include a clear description of your changes, relevant issue references, and screenshots for UI changes.

## 🔒 Responsible Security

Report security vulnerabilities privately to the project maintainers. Do not disclose sensitive information through public issues.
